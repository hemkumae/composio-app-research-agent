Methodology and Limitations

Research Methodology

The research pipeline used web search and webpage extraction to gather information about application APIs, authentication, credential access, MCP support and integration feasibility. Structured extraction was performed using a local language model, with evidence URLs retained in the research records.

Manual Verification

A sample of 20 applications was selected, with two applications from each of the ten categories. Official documentation was used where available to review API, authentication, credential access and MCP claims.

Data Limitations

  • Only 20 of the 100 applications received manual review.
  • API agreement measures only 18 comparable positive API cases.
  • MCP classification has a high unknown rate.
  • Credential-access classification is mostly unclear.
  • Buildability has not been independently established for most applications.
  • Automated keyword classifications may not capture all account, subscription or permission requirements.
  • Documentation, authentication policies and MCP support can change.

Interpretation

Unknown does not mean unsupported. It means the research pipeline did not establish sufficient evidence for a reliable classification. Manually corrected MCP values are presented separately from the agent's original findings.
