API & MCP App Research Agent

A Python/Jupyter prototype for collecting evidence about SaaS APIs, authentication, developer credential access, MCP availability, and integration feasibility.

Prototype status: This is an in-progress implementation. Tavily search and webpage reading were tested. The OpenAI extraction call was blocked by an API response indicating no remaining credits. The 100-app research, independent verification, measured accuracy evaluation, and data-backed findings dashboard have not been completed. No results or accuracy figures are fabricated on this page.

Research scope

10 starter applications across communication, email, CRM, payments, and project management. Replace the starter list with the assignment's full 100-app list.

Search layer

Tavily search for official developer documentation, authentication guides, API references, and MCP evidence.

Search tested

Page reader

Requests and BeautifulSoup extract readable text from many static documentation pages. Some sites may block automated reading or require JavaScript.

Reader tested

Extraction & verification

Structured LLM extraction and a second-pass review are implemented in the notebook, but not yet executed successfully due to API billing limits.

Not yet validated

Pipeline

  1. Load an app list and category labels.
  2. Search official API and developer documentation.
  3. Read source pages and retain evidence URLs.
  4. Extract API availability, auth methods, credential access, MCP status, and blockers.
  5. Re-check a sample and flag uncertain claims for human review.
  6. Analyze only the records actually collected and manually verified.

Repository contents

  • Jupyter notebook — runnable research workflow.
  • Starter app list — editable input file.
  • Requirements — Python dependencies.
  • README — setup, limitations, and verification instructions.

Responsible reporting

Search results are evidence leads, not proof. Prefer official vendor sources, distinguish native MCP support from third-party connectors, report unknowns honestly, and calculate accuracy only against a manually checked ground-truth sample.
